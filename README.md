# Replication package — Endogenous Switching Regression with Heterogeneous Selection on Gains

Araar, A. (2026). *Endogenous Switching Regression with Heterogeneous Selection
on Gains: Assumptions, Tests, and Estimation.* Working paper, Université Laval
and PEP.

This package reproduces every table and figure of the paper, in Python and in
Stata, from the same data. The Stata command itself (`esreg` and its family) is
distributed separately as an installable package (repository `esreg`); the ado
files are included here as well so that the package is self-contained.

## Layout

```
python/     esreg/  reference library (likelihood, fiml, twostep, effects, tests, diag, api)
            validate_esreg.py, check_score.py, smoke_het.py     validation of the library
            mc_common.py, esr_fiml_reference.py                 designs of paper A (Araar 2026a)
            mc_spec.py, mc_kappa_x.py, mc_sufficiency.py, mc_strength.py, mc_normal.py, mc_pdid.py
                                                                Monte Carlo of Section 6 (outputs *.txt)
            export_kx.py, export_suff.py, export_link.py, export_wt.py   simulated samples of data/
stata/      esreg.ado, esreg_lf1.ado, esreg_engine.ado, esreg_mata.ado, _esreg_getest.ado,
            _esreg_data.ado, _esreg_effects_post.ado, esreg_p.ado, esrdiag.ado, esrtest.ado,
            esrcurve.ado, esrmte.ado, _esreg_pwr.ado, esrreport.ado   the command family
            *_test.do            validation do-files, one per command (expected Python values printed)
            etregress_check.do   esreg against etregress (Section 8.4)
            esreg_wt_test.do     weights, hsize(), the svy prefix
            sec7_union3.do       Section 7: tables 3-6, figures, reading sheet
data/       esr_sim, esr_annex2, esr_skew, esr_nonlin (Araar 2026a,b); esr_kx, esr_suff, esr_dh,
            esr_link, esr_wt (this paper, seeds in the export scripts); union3, drugexp (Stata Press)
logs/       the Stata logs of every do-file, as run for the paper (StataNow 19.5)
paper/      esreg.tex, the draft PDF, the figures and the reading sheet of Section 7
package/    the installable Stata package (same ado files plus the help files, esreg.pkg
            and stata.toc): net install esreg, from("<path to this package folder>")
run_stata.bat   runs a do-file in batch from this folder (edit the path to Stata)
```

## How to reproduce

Python (3.10+, `pip install -r python/requirements.txt`), from `python/`:

```
python validate_esreg.py          # Table: the library against movestay / msat values
python mc_spec.py 200             # Section 6, selection-equation block   (mc_spec.txt)
python mc_kappa_x.py 200          # constant-kappa block                  (mc_kappa_x.txt)
python mc_sufficiency.py 200      # sufficiency block                     (mc_sufficiency.txt)
python mc_strength.py 100         # strength block                        (mc_strength.txt)
python mc_normal.py 100           # normality block                       (mc_normal.txt)
python mc_pdid.py 200             # pseudo-DiD block                      (mc_pdid.txt)
python export_link.py             # esr_link.dta and its reference values, etc.
```

Stata (16 or later), from this folder:

```
run_stata.bat stata\esreg_test.do        run_stata.bat stata\esrtest_test.do
run_stata.bat stata\esrcurve_test.do     run_stata.bat stata\esrdiag_test.do
run_stata.bat stata\esrmte_test.do       run_stata.bat stata\esrreport_test.do
run_stata.bat stata\etregress_check.do   run_stata.bat stata\esreg_wt_test.do
run_stata.bat stata\sec7_union3.do       (Section 7; writes paper\fig_union3_*.pdf)
run_stata.bat stata\esreg_pkg_test.do   (installs package\ and runs the commands from it)
```

Each do-file loads the ado files from `stata/` with `run`, prints the Python
reference values next to the Stata output, and writes its log to `logs/`.

## Mapping to the paper

| Paper | Produced by |
|---|---|
| Table 2 (Monte Carlo) | `python/mc_*.py` → `python/mc_*.txt` |
| Tables 3–6, Figure 1 (Section 7) | `stata/sec7_union3.do` → `logs/sec7_union3.log`, `paper/fig_union3_*.pdf` |
| Section 8.4 (validation against etregress) | `stata/etregress_check.do` |
| Single-sample values quoted in Section 4 | `stata/esrtest_test.do`, `stata/esrdiag_test.do`, `python/export_*.txt` |
| Weights and svy (Section 8.3) | `stata/esreg_wt_test.do`, `python/export_wt.txt` |
